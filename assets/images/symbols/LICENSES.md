# Symbol logo sources (self-hosted, transparent, built by tools/build-symbol-logos.py)
- crypto/*.svg: spothq/cryptocurrency-icons (npm `cryptocurrency-icons`), CC0 1.0. Public domain dedication.
- crypto/*.webp, s/*.webp (US stock, ETF-issuer and crypto marks): github.com/nvstly/icons, a public logo collection (transparent / light variants), re-encoded to 72 px WebP (<= 8 KB). The repo carries no licence file; marks stay the trademarks of their owners and are shown only to identify the symbol (nominative use). Remove any file on a rights-holder request.
- Futures / index / volatility / commodity icons and forex flags: drawn in assets/symbol-logos.js and assets/fx-flags.js. Nothing copied.
- s/<flag>: in assets/images/symbols/map.json a stock marked "w" is a white mark (inverted on the light theme), "k" a black mark (inverted on the dark theme).
- NSE India top 200: no source with a usable file list found; those rows show the neutral initials badge for now.
