Install the Mac app

Beta · macOS 11+ · Apple Silicon and Intel · Last updated 21 November 2026

The TradeZoro Mac app opens tradezoro.com in its own window, with pop-out charts and notifications. There is one download for Apple silicon (M1 or newer) and one for Intel Macs.

The beta is not notarized by Apple yet. macOS will warn you the first time you open it because it does not know the publisher, not because anything was found. The steps below open it once; after that it opens normally.

1. Download and install

  1. Download TradeZoro-mac-arm64.dmg (Apple silicon) or TradeZoro-mac-x64.dmg (Intel; Apple menu, About This Mac shows which you have) from the download page.
  2. Open the file. A window shows the TradeZoro icon and the Applications folder.
  3. Drag TradeZoro into Applications, then eject the disk image.

2. First open: macOS 11 to 14

  1. Open Applications in Finder.
  2. Right-click (or Control-click) TradeZoro and choose Open.
  3. Click Open in the box that appears.

3. First open: macOS 15 or newer

Newer macOS no longer shows an Open button in that box. Do this instead:

  1. Try to open TradeZoro once. macOS says it cannot verify the app. Click Done.
  2. Open System Settings, then Privacy & Security.
  3. Scroll down to Security. Next to "TradeZoro was blocked", click Open Anyway and confirm with your password or Touch ID.
  4. Open TradeZoro again and click Open.

Then sign in with your TradeZoro account. Your charts and settings are already there.

Updates

The Mac app does not install updates by itself. When a new version is out, a banner says New version available. Click Download, which opens the download page. Install it the same way and replace the old one in Applications.

If it still will not open

  • Check you dragged the app to Applications and are not opening it from inside the disk image.
  • Check the file you downloaded is complete: the checksum is on the releases page (run shasum -a 256 TradeZoro-mac-arm64.dmg in Terminal).
  • Still stuck? Contact support from the Help Center.
